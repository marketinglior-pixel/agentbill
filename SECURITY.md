# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AgentBill, please report it privately.

**Do not open a public GitHub issue.**

Email: marketinglior@gmail.com

You can expect a response within 48 hours. If the vulnerability is confirmed, we will release a fix as soon as possible.

## Supported Versions

| Version | Supported |
|---|---|
| 0.3.x | ✅ |
| < 0.3 | ❌ |
